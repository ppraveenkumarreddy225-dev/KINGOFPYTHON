Important setup

This app runs real Python using Pyodide. The first opening needs internet to download the Python engine. Open it once online and wait for “Python ready”. After the browser has cached the engine, the app can run core Python offline. It must be hosted on HTTPS (such as Netlify); opening the HTML file directly will not support offline caching.
